6 issues found & fixed mid-session
  1. Prototype-pollution validation bypass — bracket lookup on a plain object let constructor/toString/__proto__ etc. skip unknown-key rejection. Fixed with Object.hasOwn, 12 regression tests.
  2. Save-before-load race + URL precedence bug — first render could PUT default state before the real save loaded (cross-device clobber risk); live URL was read at hydrate time instead of snapshotted, breaking "URL wins over server" precedence. Both fixed, covered by E2E.
  3. Missing favicon — 404 on every page load. Fixed with an inline SVG data-URI icon.
  4. Plaintext HTTP accepted — Basic Auth challenge was servable over unencrypted HTTP with no redirect. Fixed: 308 redirect (checks both Cloudflare scheme signals, OR'd) + HSTS, with a loop-guard and a dev-only escape hatch so local testing didn't break.
  5. Remote deploy migration command was broken — wrangler d1 migrations --remote ignores account_id from config on a multi-account machine; would have failed silently at deploy time. Pinned via cross-env.
  6. Duplicate package.json key — cosmetic, wrangler warning on every run. Removed.
