เปลี่ยน HTTP Basic Auth เป็นหน้า login + กัน brute force

บันทึกเมื่อ 2026-09-03 · โปรเจกต์ gravship-worker-web (rim.jairukchan.com)

คำขอเดิม (คำต่อคำ)

username pass ควรเป้นหน้า login ดี ๆ ไม่ใช่ js alert แบบนี้ เอาให้เข้ากับ style app ด้วยนะ และทำ rate limit พื้นฐานด้วย อย่าให้ bruce forece ได้

สรุปเป้าหมายที่ตกลงกัน

ประเด็นข้อตกลง
แทนที่อะไรBrowser-native HTTP Basic Auth popup (authenticate() ใน src/worker.js) — ผู้ใช้เรียกว่า "js alert"
ด้วยอะไรหน้า login แบบ HTML form จริง สไตล์ตรงกับ public/index.html (พาเลทเขียว, การ์ดโค้งมน, shadow เดียวกัน)
SessionSigned cookie (HMAC), ไม่ต้องมี KV/session store เพิ่ม — ใช้ D1 ที่มีอยู่แล้วเท่านั้น
Rate limitนับความพยายาม login ผิดต่อ IP ใน D1 — ล็อกชั่วคราวหลังพิมพ์ผิดซ้ำในช่วงเวลาสั้น ๆ
Credential เดิมยังเป็น single-user (AUTH_USER/AUTH_PASS คู่เดียวจาก env) เหมือนเดิม — ไม่เพิ่ม multi-user
